# Reclaimed Earth previews

London and Dhaka use the imported mmo-rpg oak/pine assets, live TerrainSampler
seating, full/medium/card tree instances, powerless ruins and recipe-controlled
street vegetation. Trees are deliberately oversized at the user's request, with
rare giants taller than Sovereign. Ordinary clearances still exclude foundations
and facilities.

Captured using the real terrain tool with compatibility rendering and lightweight
clouds. These show appearance and shader execution; they do not measure the user's
GPU frame rate. At speed, scenery coverage widens by sampling stable seats more
sparsely and returns to full density when flight slows.

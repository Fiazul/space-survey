Real global topography (16-bit-precision height maps, public domain):
  mars_height_2k.png, moon_height_2k.png — 2048x1024 equirectangular, RGB8
  PNG, value = R*256 + G (R=high byte, G=low byte, B unused). Godot 4.6.3
  flattens a single-channel 16-bit PNG to 8-bit on load (measured,
  tools/probe_dem16.gd); this two-channel byte-pack round-trips exactly
  through Image.load() (same probe) and is stored with the texture importer's
  compress/mode=0 ("Lossless") like every other file in this folder, so no
  VRAM-compression quantization is introduced either.

  Longitude convention: column 0 = lon 0E in the raw PDS3 files (verified:
  Mars argmax sample 21134 m lands within 1px of Olympus Mons at 18.65N
  226.2E). mars_2k.jpg / moon_2k.jpg instead put lon 0 at the image's
  HORIZONTAL CENTER (verified against known maria/albedo contrast — see
  docs/research/2026-09-09-dem-ingest.md for the numbers) — the DEMs are
  rolled by half the source width before resampling so they line up with the
  existing albedo maps texel-for-texel.

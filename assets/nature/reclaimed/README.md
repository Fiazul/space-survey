# Reclaimed forest kit

Copied from the local mmo-rpg `assets/nature_vale` kit: oak_a and pine_a,
each with full, simplified and four-triangle crossed-card detail levels.
Models and foliage atlases were authored procedurally for that project.
Bark derives from [Poly Haven bark_willow_02](https://polyhaven.com/a/bark_willow_02), CC0.
Shared texture files retain the source naming and GLB relative image paths.

Runtime normalizes all three levels to 30 m before recipe instance scaling.
Earth's recipe uses 110 m trees with deterministic 0.72–1.28 variation and
rare ancient trees around 250–440 m, per the requested ship-scale forest direction.
The latter are an intentional art direction, not a claim about real tree heights.
Only 64 trees may use full meshes and 512 simplified meshes simultaneously.

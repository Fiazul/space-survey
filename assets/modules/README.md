# Ship modules

Swappable weapon and landing-pad modules, generated by `tools/blender/build_modules.py`
(helpers: `tools/blender/module_common.py`). Contract: `docs/specs/2026-09-26-ship-roster-and-modules.md`.
Never hand-edit the GLBs — change the script and rebuild.

| File | What | Tris | Extra empty (Godot frame) |
|---|---|---|---|
| `weapon_mk1.glb` | Single plasma accelerator: tapered cheek shrouds, recessed cooling slots, sight spine and inset emitter | 1792 | `MUZZLE` (0, -0.85, -4.5) |
| `weapon_mk2.glb` | Twin plasma accelerator: swept shrouds, exposed central rails, narrow charge strips and twin recessed emitters | 2572 | `MUZZLE` (0, -0.9, -5.9), centred between barrels |
| `pad_mk1.glb` | Trailing-link gear: paired structural arms, knee pivots, polished piston, torque scissors and broad chamfered foot | 1332 | `FOOT` (0, -4.62, 0) |
| `pad_mk2.glb` | Heavy trailing-link gear: wider stance, auxiliary dampers and inset approach light | 1452 | `FOOT` (0, -4.73, 0) |

Budget: ≤ 3000 tris per module (build script aborts over budget; `tools/test_module_glbs.gd` re-checks).

## Convention

- Metres, Godot frame after import: +X right, +Y up, -Z forward. One mesh + one empty per GLB.
- Weapons: origin = hull attach point = top face of the saddle. The cannon hangs below it
  (-Y), barrel toward -Z. `MUZZLE` sits at the emitter mouth.
- Pads: origin = hull attach point = top of the mount plate (on the hull skin). Modelled in the
  DEPLOYED pose along -Y (~4.6 m); runtime retracts by translating/scaling along Y. `FOOT` is the
  ground contact point (bottom of the sole).
- Materials: `Hull_Paint`, `Hull_Dark`, `Hull_Steel`, `Accent_Emit` only (no textures).
- Blender authoring axis: the glTF exporter maps Blender **+Y** → Godot **-Z** (measured: an
  empty at Blender (0,1,0) exports to glTF (0,0,-1)). `module_common.g(x, y, z)` converts Godot
  coords to Blender, so the build script is written in Godot terms.

## Commands

```
blender -b --python tools/blender/build_modules.py                          # all four
blender -b --python tools/blender/build_modules.py -- --module weapon_mk2   # one
blender -b --python tools/blender/render_modules.py -- --out /tmp/modules   # review renders (Cycles CPU, ~2 min)
timeout 600 godot --headless --import --path .
godot --headless --script tools/test_module_glbs.gd                         # → "module_glbs: OK"
```
